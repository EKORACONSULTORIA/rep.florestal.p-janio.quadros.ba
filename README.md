# Dashboard de Gestão de Ativos Ambientais — Reposição Florestal | UFV Apolo Presidente Jânio Quadros/BA

Dashboard executivo interativo (HTML/Chart.js) do monitoramento do plantio compensatório,
cercamento e sistema de irrigação — UFV Apolo Presidente Jânio Quadros/BA, **Agosto/2026**.
Bragagnoli Ambiental (CTF/AIDA 8805586) · EKORA Consultoria Ambiental.

## Deploy (GitHub Pages)
1. Criar repo → subir `index.html` e `assets/logo-ekora.jpg`.
2. Settings → Pages → Branch: `main` /root → Save.
3. URL: `https://ekoraconsultoria.github.io/rep.florestal.p-janio.quadros.ba/`

## Conteúdo
- Visão Geral (KPIs, indicadores de monitoramento, painel comparativo, desempenho ambiental)
- Monitoramento das Mudas (espécies nativas, desenvolvimento vegetativo, campanhas, comparativo Junho × Julho × Agosto)
- Indicadores Ambientais (Tabelas 6.3, 6.5, 6.5.1, semáforo ambiental)
- Avaliação Fitossanitária (herbivoria, doenças, sistema de irrigação)
- Execução do Programa (ações de manejo, área monitorada, coordenadas UTM, cronograma de 24 campanhas)
